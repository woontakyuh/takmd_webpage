# Soft Pad Executive chair

Original 3D model by **Laci Lacko (LaciViz)**, based on the Eames Soft Pad chair by Charles and Ray Eames.

- Source and usage permission: https://www.laciviz.com/freebies.html
- Original project: https://www.behance.net/gallery/72799495/Herman-Miller-FREE-3D-model
- Retrieved: 2026-09-07.

The author permits free commercial and non-commercial use and asks that the model not be resold or redistributed as one's own work. This is an attributed derivative for the TakMD interactive office, not an original model by TakMD and not an official Herman Miller digital product.

Adaptations: mesh reduction, metre scale (1.08 m high), ground contact and orientation normalization, warm beige leather and polished aluminum PBR materials. Source geometry retains the separate back cushions, stitched welting, open armrests, rear crossbar, tilt mechanism, and five-caster base.
