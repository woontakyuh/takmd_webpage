# North-bank low-rise fabric

[urban-fabric.json](./urban-fabric.json) is derived from © OpenStreetMap contributors and is shared under [ODbL 1.0](https://www.openstreetmap.org/copyright). It restores 1,000 small, mapped building footprints omitted by the original 850-building area-ranked selection. It does not alter that original database or its indices. The first 380 entries remain identical to the earlier foreground layer.

The source is the saved Overpass building response downloaded on 2026-09-09, whose response metadata reports the OSM base timestamp **2026-07-15T15:22:01Z**. The repository includes the complete response at `scripts/fixtures/banpo-buildings-osm-2026-07-15.json.gz`, compressed SHA-256 `411850ba204c790a540e395e5678509da162c0556b4b7a45d7bc600ada0a00b5`. Its decompressed SHA-256 is `30e4c48866220d1170825f1812becdb2eeba9f7247f6065acb0091df13ef8687`, identical to the original downloaded response. Original `geography.json` remains byte-identical, SHA-256 `cafdeced83e1435b791ab3621b01406fbf88e19b8052699342b760acdeddaffc`.

Generate deterministically with `bun scripts/prepare-banpo-urban-fabric.ts` from the repository root. The command reads the tracked compressed fixture directly; no `.omo` evidence directory or network request is required. Each output retains its OSM ID, polygon, terrain base, height, area and tagged-height flag.

The preparation uses the existing origin, 37.5101 N / 126.9918 E, and rounds projected coordinates to 0.1 m. Selection is confined to east −2,500…3,000 m and north 650…4,200 m, footprint areas at least 50 and below 500 m², and heights at most 28 m. It excludes existing buildings, river cells, and every intersecting park or woodland feature in [landcover.json](./landcover.json). Even-odd inner rings remain exclusions from protected cover, so a mapped building inside a park polygon's hole is permitted. These are the existing simplified landcover boundaries, not a survey.

`measured: true` means an OSM `height` or `building:levels` tag exists; it does not mean independently surveyed. Thirteen selected buildings have tagged heights; 987 use an explicit 11 m estimate. Levels convert at 3.05 m per floor. Untagged apartment buildings are excluded because their existing 44 m estimate exceeds this layer's height limit. Terrain bases use the existing terrain surface, with a 0.2 m foundation overlap.

The expanded extent contains 3,176 eligible source footprints before applying the rendering budget. The layer retains the previous 380 nearest footprints within the original extent, then cycles through 500 m geographic cells to give the remaining mapped districts representation instead of spending the entire budget on one dense neighborhood. Cell order and each cell's entries use the existing center-distance ranking with OSM IDs as tie breakers. This sampling changes neither footprints nor their locations. Selection stops at 1,000 buildings or 20,000 triangles.

The current output contains 15,325 triangles in the same two merged wall/roof meshes, with no added shadows, image textures or per-frame geometry work. This adds 8,813 triangles over the earlier 380-building layer. The 157.6 kB JSON is bundled into the existing scene chunk; it adds no separate runtime request. Ground forecourts automatically include all selected footprints using the existing 1024² material mask, with protected park/woodland cover painted last. No additional mask, texture fetch, or terrain paving outside the existing mapped urban areas, road margins and building forecourts is added.

Hill lighting now uses central differences from the same 100 m SRTM height grid to share surface normals across terrain material batches. The geometry, elevations and coastline stay unchanged. Terrain at 35 m or lower keeps its original normals; the change blends in between 35 and 65 m, with invalid or water-adjacent source samples excluded. This reduces visible triangular lighting facets without adding geometry or runtime animation.

Base facade windows are illustrative, stable shader detail: a world-position seed varies occupancy by block, room and floor, with warm and occasional cooler lights. Day/night changes a single uniform per material; occupancy has no clock or CPU animation. The existing 49 dimensional facade attachments remain unchanged.

Visual direction comes from the supplied Banpo view in `docs/reference-assets/han-river-2026-09-09/reference-06.png` and daytime panorama `reference-02.png`: low-rise neighborhoods behind a thin green riverbank, with Namsan retained. The photos establish visual density and material hierarchy, not exact individual heights or windows. The [official Banpo Hangang Park description](https://hangang.seoul.go.kr/www/contents/663.do?mid=463) supports retaining the riverside park and separated paths. No photograph or map image is shipped in the window view.

This remains a selective geographic interpretation. The original 100 m terrain, existing building count and bridge axes are preserved; untagged heights, window occupancy, roof materials and facade colors are visual estimates.
