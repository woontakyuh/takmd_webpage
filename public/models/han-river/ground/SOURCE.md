# Riverbank ground surfaces

Leafy Grass by Charlotte Baglioni / Poly Haven, CC0.
https://polyhaven.com/a/leafy_grass
https://polyhaven.com/license

Official 1K diffuse and OpenGL normal maps downloaded through the Poly Haven files API on 2026-09-09; API MD5 hashes verified. Public web derivatives are 512px WebP. Original downloads and metadata remain in local task evidence.

Compacted soil uses the existing Grass Path 2 by Rob Tuytel / Poly Haven (CC0), documented in public/textures/river-LICENSE.txt. Urban hardscape coverage is derived from the existing OSM building footprints and mapped roads in geography.json (ODbL). These are ground material maps applied to the existing 3D terrain, not a panorama or scene photograph.
