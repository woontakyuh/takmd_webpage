# Noguchi coffee table

- Source mesh: [Noguchi coffee table, Flareworks Studio / Daniel Lee](https://www.blendkit.com/asset-gallery-detail/499820e7-b642-4756-9042-73604627b3f1/), downloaded 2026-09-07. Asset base ID `499820e7-b642-4756-9042-73604627b3f1`, revision `36608956-dcaa-4195-9f85-76bf2aee5bdb`.
- License: **Creative Commons Zero (CC0)**, confirmed on the asset page and API (`license: cc_zero`). The original file and license evidence are archived in `docs/reference-assets/noguchi/`.
- Product design: Isamu Noguchi's coffee table. This is an independently authored artist model, not an official Herman Miller CAD export or an endorsement.
- Adaptation: original sculpted twin interlocking wood legs and rounded triangular glass surface retained; natural pale ash colour baked from the source wood texture, 1K texture, merged wood geometry, optimized subdivision and mesh density. Glass uses separate clear faces and a green cut edge, alpha transparency and standard PBR reflection with no real-time transmission render pass.
- Reference scale: **1.26 m wide × 0.90 m deep × 0.37 m high**, matching the user's dimensioned reference. This is a visual reference size rather than the official Herman Miller specification. Local model X is width, Y is height, Z is depth; bottom is Y=0 and the footprint is centred at X=Z=0.
- Limitations: the source artist's outline and assembly are retained rather than claimed millimetre-identical to manufacturer CAD. Pale ash colour is a visual adaptation. Lightweight glass retains transparency, highlights and a green edge; it does not simulate refractive distortion or caustics.

The official [Herman Miller model page](https://www.hermanmiller.com/resources/3d-models-and-planning-tools/product-models/individual/noguchi-table/) was inspected. Its SketchUp file was not used in the delivered GLB because a public redistribution grant was not established from the general site terms.
