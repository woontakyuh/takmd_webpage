# Davos Hospital sleeve emblem

`davos-hospital-emblem.png` is the hospital's unchanged transparent circular emblem, supplied in its official PNG identity package. It is used on the physician coat's wearer-left sleeve at the owner's request.

- Official identity page: https://www.davoshospital.co.kr/intro/page03.html
- Source package: https://www.davoshospital.co.kr/intro/PNG.zip
- Original entry: `다보스로고엠블럼.png` (159 × 138 pixels)
- Retrieved: 2026-09-07

The runtime decal follows the sleeve surface and uses a matte material. The generated coat itself remains a 3D interpretation, not a scan of the owner's actual uniform.
