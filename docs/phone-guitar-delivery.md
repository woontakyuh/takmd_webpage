## Phone delivery copy (2026-09-22)

`stratocaster-phone.glb` is generated by `scripts/build-phone-guitar.mjs` from the existing runtime original. All compressed geometry buffers, vertex/index order, accessors, node transforms, materials and attribution remain unchanged. Its six embedded textures contain the exact pixels produced by the existing browser canvas resize to 1024px, stored as lossless WebP. The desktop keeps the original 2048px textures. This removes the redundant full-resolution download, decode and client-side resize on phones without lowering their existing texture resolution.
