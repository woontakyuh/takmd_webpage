# Hover interactions · 2026-09-08

The office uses material, light, and local articulated-part responses in place of a shared hover lift or object scaling. Hovering any part of the award triggers its existing polished-inset glint. Clicking still focuses first, and only the focused inset opens YouTube.

Implemented in this pass:

- Wall TV: derive left/right colors from the displayed cover edges, then brighten only the concealed four-edge rear Hue strip. The horizontal pair keeps all four physical edges harmonious with the current content. An unreadable image uses a quiet neutral pair.
- Work monitor and electronic photo frame: rest slightly dim, then brighten.
- Research folio: raise the physical cover by about 20 degrees.
- Palm: sway the foliage canopy around its soil-level pivot; the planter and stand remain still.

Possible later additions, kept out of this pass: a subtle keyboard key-backlight response, a focused reflection on the spine plinth, and a localized shade-control indicator. Each needs a content or control purpose before implementation.
