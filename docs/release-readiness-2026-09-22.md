# TakMD 공개 배포 준비 점검 — 2026-09-22

## 현재 상태

기존 방과 소장품 디자인을 유지하면서 실제로 재현한 로딩·읽기·자료 표시 문제를 수정했다. 이번 작업에서는 공개 사이트에 배포하지 않았다. 기술 검증과 콘텐츠 공개 허가, 실물 기기 검증을 구분한다.

### 추가로 발견한 표시 오류

이후 데스크톱에서 기타·앰프가 누락되고 방 밖의 벽이 방을 가리는 문제가 보고되어 별도로 재현·수정했다. 아래의 기존 전체 검사 결과는 이 두 시나리오를 포괄하지 않았다.

- 초기 오브젝트: 기타·앰프 등이 방을 먼저 연 뒤 브라우저의 idle 시간을 기다려 나타나는 구조였다. 해당 지연 처리를 없애고, 모형·가운·도복·서핑보드·액자·상장·책등·CD 케이스가 준비된 후에 로딩 화면을 닫는다. 닫힌 술장 안쪽과 책 내부처럼 아직 보이지 않는 상세 자료만 별도로 불러온다.
- 외벽: 정적 메시 병합이 벽의 숨김을 제어하는 부모 바깥에 새 메시를 만들었다. 같은 부모의 물체끼리만 병합하도록 고쳐 방 밖에서는 해당 벽이 사라지고 안에서는 다시 보이게 했다.
- 모바일 기타 표면: 2048px ImageBitmap을 GPU 한도 1024px로 줄일 때 이미지 업로드 방향이 이전 상태를 물려받았다. 크기를 맞춘 독립 텍스처를 사용해 원본 모델·재질과 GPU 한도를 유지하면서 방향을 고정했다.
- 벽 가시성 회귀 검사 4개와, 세 화면 크기에서 최초 준비 순간의 모든 주요 물체·기타/앰프·확대·실제 드래그·안팎 벽을 확인하는 브라우저 검사를 추가했다. 배포 전 브라우저 검사 목록은 5개에서 6개로 늘어났다.
- 초기 화면 추가 검증: 빌드 `7bc9255-mucagyvw`에서 데스크톱·태블릿·모바일마다 파일 하나를 지연시켜도 먼저 열리지 않았고, 최초 준비 시점에 주요 물체 13개·CD 케이스 10개·책등 8개가 표시됐다. 27개 화면 캡처, 파일 실패 후 재시도, 전체 단위 검사 357개도 통과했다.
- 추가 증거: `.omo/evidence/office-visibility-2026-09-22/`. 기존 전체 검사 빌드와 추가 수정 빌드를 혼동하지 않는다. 추가 수정도 아직 운영 배포하지 않았다.

## 반영한 변경

- 모바일 Research도 UBE와 같은 자연스러운 읽기 화면을 사용한다. 본문을 스크롤한 만큼 화면이 올라오고, 맨 위로 돌아오면 방이 다시 보인다. 별도의 안쪽 스크롤을 제거했다.
- 읽는 동안 키보드 초점이 뒤쪽 방으로 빠지지 않는다. 닫으면 열었던 위치로 돌아간다. 사진 확대 창과 포인터로 방을 조작하는 기존 동작은 유지했다.
- 아직 슬라이드가 없는 발표도 제목·일자·장소·역할과 자료 상태가 읽히는 화면으로 표시한다. 실제 TV와 조작 화면이 같은 디자인 데이터를 사용한다.
- 모바일 Contact를 다시 노출하고 터치 영역을 확보했다. 취소된 10월 16일 KNS 일정은 달력에서도 제거했다.
- 닫힌 술장의 병 라벨 7개는 방이 준비된 뒤 불러온다. 내부 재질을 미리 준비하는 동작은 유지한다.
- 장면 로딩에 실패하면 기존 로딩 화면에서 바로 재시도할 수 있다. 읽으려던 URL을 유지한다.
- 압축 모델을 푸는 필수 파일을 사이트에 포함해 외부 서버 의존성을 제거했다. 원본 파일과 라이선스·출처·해시를 함께 보존했다.
- 제작용 모델 뷰어를 공개 폴더 밖으로 옮겼다. 콘텐츠·프레임·기기 권한 정책을 추가하고, 실제 3D·음악·영상과 호환되는지 검사했다.
- 배포 명령 앞에 `check:release` 검사를 연결했다. 실패한 검사가 있으면 배포 단계로 넘어가지 않는다.

## 남아 있는 확인 사항

1. **의존성 정비:** 현재 감사 결과는 16개 패키지의 경고 54건이다(심각 1, 높음 28 포함). 검토된 공개 사이트는 정적 파일이고 방문자 집계 함수는 해당 npm 패키지를 가져오지 않아, 이 결과만으로 공개 서버의 Astro/Sharp 취약 경로가 확인된 것은 아니다. 그러나 제작·빌드 도구의 취약점은 남아 있다. 신뢰하지 않는 AVIF/HEIF를 처리하지 말고 Astro/Sharp 및 빌드 도구를 별도 변경으로 업그레이드하고 재검증해야 한다.
2. **실제 방문 환경:** 실물 iPhone·Android, 저사양 기기의 장시간 발열/메모리, 여러 해외 지역의 망에서 측정한 결과는 아직 없다. 이번 로컬 브라우저 결과를 그 검증으로 대체하지 않는다.
3. **공개 콘텐츠:** 음원·책 내부 페이지·학회/워크숍 사진의 공개 권한, 인물 동의와 임상 자료의 식별 가능성은 코드 검사만으로 확정할 수 없다. 이번 기술 검사에서 허가가 확인됐다고 간주하지 않는다.
4. **릴리스 파일:** 현재 작업 폴더의 새 소스·이미지·모델·검사 파일 중 Git 미추적 파일이 있다. 커밋할 때 출처가 불분명한 파일을 일괄 추가하지 말고, 빌드에 쓰인 파일을 빠짐없이 포함했는지 확인해야 한다.
5. **게시 이후:** 실제 Pages 응답의 보안 헤더, 빌드 ID, 주요 진입 경로를 한 번 더 확인해야 한다. 현재 로컬 결과와 운영 배포를 혼동하지 않는다.
