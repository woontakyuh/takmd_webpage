# 전자액자 사진

이 폴더에 홈페이지에 공개할 사진을 넣어주세요. JPG, PNG, WebP를 지원합니다.

```sh
bun run photos:import
bun run build
```

사진은 긴 변 1400px의 WebP로 변환되고 위치정보 등 원본 메타데이터는 제거됩니다. 배포 후 방문할 때마다 한 장을 골라 표시합니다. 사진이 두 장 이상이면 같은 브라우저에서 직전 방문의 사진은 건너뜁니다.

폴더를 편집한 것만으로 운영 사이트가 바뀌지는 않습니다. `photos:import` 후 커밋·배포하면 반영됩니다. `--clear`를 지정하면 등록된 사진을 모두 비웁니다. 사진이 없을 때는 이미 공개된 프로필 사진을 표시합니다.

원본은 이 폴더에 보관하고, 웹에 배포할 최적화 사본과 목록은 `public/images/photo-frame` 및 `src/data/photo-frame.json`에 생성합니다.
